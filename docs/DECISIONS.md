| D38 | 2026-11-03 | `internal/hc` has a framed mode (#163): `DialFramed` sends `hello{generation:1,framed:true}`, then the connection carries frames, and `Attach` returns a `Stream`. Channel 0 carries JSON-RPC (one message per DATA frame, requests too); an attach gets its own channel from the reply. Kinds: 0 DATA (terminal bytes; input from the viewer), 1 CREDIT (uint32 bytes consumed), 2 CLOSE (core: JSON `{reason}`; viewer: empty), 3 RESIZE (uint16 cols, uint16 rows; viewer to core, and core to an observer or a `resize_notifications` viewer), 4 FOCUS (1 or 0), 5 FACTS (JSON display facts), 6 AUTOMATIC_INPUT (terminal replies, not human input; unused).

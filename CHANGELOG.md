# Changelog

This file records completed changes. Each work PR adds its entry in the same PR. Dates use YYYY-MM-DD.

## 2026-10-23

- Type into the focused herdr tab (S7 of #4). Keys, Ctrl chords, function keys and Shift-Enter go to the
  focused pane. Dead keys and Option characters arrive as text through the IME. Cmd-V pastes the clipboard
  text. A click takes the keyboard. A reconnecting surface is dimmed. A failed link start is tried again on
  the next click or key, not on a timer. A redraw of the frame no longer paints the terminal again.
